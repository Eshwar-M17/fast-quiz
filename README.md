# Quiz App (Flutter)

Quiz App is an Android application built using Flutter that enables users to answer multiple-choice questions and view their final scores. With a seamless question progression and an intuitive user interface, this app offers an engaging way to test knowledge and track performance.

## Features

- **Multiple-Choice Questions:** Users can tackle MCQs across various topics.
- **Score Calculation:** Displays the final score upon quiz completion.
- **User-Friendly Interface:** Smooth navigation and responsive design optimized for Android.
